# PDF workflow

1. Inspect document metadata, page count, text availability, forms, encryption, and signatures.
2. Prefer a connected PDF MCP tool. Otherwise use an existing project library or installed PDF utility without silently adding dependencies.
3. Preserve source quality and form behavior. Never flatten signatures or interactive fields unless requested.
4. Render changed pages and inspect text, images, annotations, redactions, clipping, and page order.
5. Reopen the final file to confirm it is readable and structurally valid.
6. State clearly when no executable PDF tool is connected or installed.
