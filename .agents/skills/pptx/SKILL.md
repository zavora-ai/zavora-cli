# Presentation workflow

1. Inspect the existing deck, template, brand assets, and requested audience.
2. Prefer a connected slides MCP tool. Otherwise use an existing project library or installed presentation tool without silently adding dependencies.
3. Reuse the source theme and layouts when editing. Keep one clear message per slide and use visual hierarchy rather than dense prose.
4. Preserve speaker notes and accessibility metadata unless the request says otherwise.
5. Render every slide to images and inspect clipping, contrast, alignment, overflow, and font substitution.
6. State clearly when no executable presentation tool is connected or installed.
