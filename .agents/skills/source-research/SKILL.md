# Research workflow

1. Prefer primary, authoritative, and current sources.
2. Separate source claims from inference and preserve direct URLs.
3. Compare publication dates with the date an event occurred.
4. Use multiple independent sources when a decision depends on disputed or incomplete evidence.
5. Keep quotations short and summarize the surrounding context accurately.
6. Report uncertainty, missing evidence, and material source disagreement.
