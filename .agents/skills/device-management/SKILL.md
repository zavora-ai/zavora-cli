# Device workflow

1. Require a connected device-management or computer-use tool before claiming device visibility.
2. Resolve the exact device, account, process, service, or setting before acting.
3. Diagnose with read-only checks first and preserve evidence.
4. Require approval for remediation, process termination, service restarts, package changes, remote commands, and bulk operations.
5. Prefer reversible changes and record rollback instructions.
6. Report per-target results; never describe a partially completed fleet operation as fully successful.
