# Repository workflow

1. Read applicable `AGENTS.md` instructions and inspect repository status before editing.
2. Discover existing patterns, dependencies, tests, and generated-file boundaries.
3. Make the smallest coherent change that satisfies the request.
4. Run focused checks first, then broader verification in proportion to risk.
5. Review the final diff and preserve unrelated user changes.
6. Commit, push, deploy, or publish only when explicitly requested.
