# Email workflow

1. Require a connected, authenticated email MCP server before claiming mailbox access.
2. Search narrowly and preserve thread context, participants, dates, and attachment names.
3. Draft messages without sending unless the user explicitly requests delivery.
4. Show the resolved recipients, subject, and material attachment changes before consequential sends.
5. Apply the runtime approval policy to sending, deleting, moving, labeling, and bulk operations.
6. Report the provider result and message identifier after a successful write.
